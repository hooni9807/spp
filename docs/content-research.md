# 공개 콘텐츠 보강 근거 · 2026-11-17

## 확인한 1차 자료

- [Google AdSense: Content and user experience](https://support.google.com/adsense/answer/10015918): 독창적 내용, 중복 최소화와 탐색의 정확성.
- [Google AdSense 공식 유튜브: Quality Content](https://www.youtube.com/watch?v=poU80MgSvrY): 사이트 승인 시 좋은 콘텐츠를 다루는 공식 영상. 확인 가능한 제목·설명과 위 공식 문서를 함께 참고했으며 영상 전체를 시청·전사했다고 주장하지 않는다.
- [Google AdSense 공식 유튜브: Navigation](https://www.youtube.com/watch?v=X_xKMJ8m6nY): 사용자가 콘텐츠 사이를 이동하기 쉬운지 점검하는 공식 시리즈.
- [ITTF Statutes 2025](https://db.ittf.com/sites/default/files/public/2025-02/2025_ITTF_Statutes_clean_version.pdf): 점수와 서브 교대의 기본을 해당 판본으로 확인. 최신 실제 대회 규칙 전체를 검토한 것은 아니다.

## 적용

검색 글과 영상을 복제하지 않고 SPP 구현을 근거로 상황 판단 훈련 12문제, 플레이 목표 안내, 실제 스포츠와 게임 규칙 차이 해설을 작성했다. 스포츠 기본 사실과 게임 고유 규칙을 구분한다. 사용자 체류 시간이나 승인 확률은 측정하지 않았으므로 수치로 홍보하지 않는다.

판정 훈련은 로그인·쿠키·서버 기록 없이 동작하며 게임 보상을 지급하지 않는다. 모든 문제 해설은 자바스크립트가 없어도 details에서 읽을 수 있다. 사이트의 게임 로그인 정책은 유지한다.

확인 범위: 공개 문서·공식 유튜브 메타데이터·로컬 코드. Google 내부 심사 원인이나 승인 여부는 확인할 수 없다.
