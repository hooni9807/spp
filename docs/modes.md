## 세계정복 난이도

세계지도에는 총 **22개국**이 표시됩니다. 난이도는 국가 이름 옆에 표시됩니다.

| 표시 | 국가 |
|---|---|
| HELL- | 독일·스웨덴·프랑스·루마니아·포르투갈·오스트리아 |
| HELL | 러시아·대만·인도·브라질·미국·싱가포르·나이지리아 |
| HELL+ | 캐나다·아르헨티나·호주·남아프리카공화국·멕시코·그린란드 |
| HELL++ | 일본·홍콩 |
| HELL+++ | 중국 |

일본은 HELL- 1개국, HELL 2개국, HELL+ 2개국을 제패한 뒤 도전할 수 있습니다. 중국은 HELL- 1개국, HELL 2개국, HELL+ 3개국, 일본과 홍콩 제패가 필요합니다. 모든 국가의 7명 출전 순서는 매 도전마다 바뀝니다.
